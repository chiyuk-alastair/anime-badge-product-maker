# Anime Badge Product Maker

A Codex skill that turns one anime collectible-figure photo or effect render into a complete three-image product set:

1. circular badge artwork;
2. a photoreal physical tinplate button-badge mockup;
3. a matching sales image using the cleaned real figure background, the exact physical badge, and the copy `马口铁胸针谷子`.

The workflow preserves character identity, removes platform and seller traces, keeps visible character names, and treats the physical badge as a real product rather than a redrawn flat circle.

## Install

Install the skill folder from this repository:

```text
skills/anime-badge-product-maker
```

After installation, invoke `$anime-badge-product-maker` and attach a figure photo or effect render.

## Outputs

- `01-badge-art.png`
- `02-badge-mockup.png`
- `03-badge-sales-image.png`
