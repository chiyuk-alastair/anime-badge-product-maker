## [1.0.0] - 2026-10-09

### Added

- One-image workflow producing badge art, a physical badge mockup, and a matching sales image.
- Explicit source cleanup policy, including character-name preservation and third-party trace removal.
- Identity, anatomy, physical-realism, consistency, and exact-copy quality gates.
- Default blank physical badge asset.
- Codex UI metadata and bilingual project documentation.
- Dependency-free repository validator and GitHub Actions workflow.
- Contribution, conduct, security, and support policies.
