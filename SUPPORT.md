# Support

## Usage questions

Open a GitHub issue using the most relevant template and include:

- Codex version or environment;
- the invocation you used;
- which stage failed;
- expected and observed behavior;
- validator output, when relevant.

Before uploading an image, remove personal information, platform account details, seller handles, prices, watermarks, and unrelated private content. A synthetic or heavily redacted reproduction is preferred.

## What support covers

- Skill installation and discovery.
- Workflow interpretation and output contracts.
- Reproducible validation failures.
- Documentation corrections.

## What support does not guarantee

- Rights clearance for copyrighted characters or source images.
- Manufacturing specifications from a badge vendor.
- Perfect recovery from low-resolution, cropped, or heavily occluded references.
- Private one-to-one production services through public issues.

Report security or privacy incidents according to [SECURITY.md](SECURITY.md), not through a public issue.
