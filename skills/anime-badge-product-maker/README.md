# Installable Skill Directory

[Project documentation](../../README.md) | [中文文档](../../README.zh-CN.md)

Copy this entire directory to the Codex skills directory. Do not copy `SKILL.md` alone: normal operation also uses `agents/openai.yaml`, the two references, and `assets/default-blank-badge.png`.

Default invocation:

```text
Use $anime-badge-product-maker to turn this figure image into the complete badge product set.
```

中文调用：

```text
使用 $anime-badge-product-maker，把这张实体手办图制作成徽章画稿、实体徽章效果图和背景图+实体徽章商品图。
```
