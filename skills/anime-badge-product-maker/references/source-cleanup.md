# Source Cleanup Rules

Use this reference when a figure source is a screenshot, contains clutter, or mixes allowed content with removable overlays.

## Text classification

| Visible content | Default action | Reason |
| --- | --- | --- |
| Character name integrated into the image | Preserve | It identifies the depicted product |
| Character name engraved on the physical base | Preserve | It is part of the photographed object |
| Franchise title or logo | Remove unless requested | It is not required to identify the individual character |
| Version label such as `七武海版本` | Remove | It is promotional copy, not the character name |
| Phone status bar, app controls, carousel dots | Remove | Platform UI |
| Seller handle, price, coupon, shipping claim | Remove | Marketplace content |
| Studio, photographer, painter, or shop mark | Remove | Third-party attribution or watermark |
| Copyright boilerplate or tiny promotional copy | Remove | Not part of the product composition |
| Ambiguous text | Remove | Do not guess its meaning |

Do not reproduce text merely because it is large or visually integrated. Classify its meaning first.

## Object cleanup

Preserve the figure, effect parts, companion motifs, display base, and genuine product accessories. Remove household or workshop clutter such as cups, kettles, ashtrays, cigarettes, tools, tape, papers, cords, cans, and furniture when they distract from the product.

When removing a room or tabletop, rebuild a clean studio or atmosphere background that supports the original palette. Keep the figure's photographic or rendered style unchanged. Do not use cleanup as permission to redesign the subject.

## Layout for the later sales composition

- Square 1:1 canvas.
- Figure left or center-left.
- Quiet upper-right region for `马口铁胸针谷子`.
- Quiet lower-right region for a badge roughly 35–42% of canvas width.
- Keep face, hands, signature object, companion face, and base inscription unobstructed.

If the source already has a strong layout, preserve it and create negative space by cleaning or extending the surrounding background rather than shrinking the figure excessively.

## Failure patterns

- Rebuilding an unavailable source from memory instead of asking for re-upload.
- Treating a character name as a watermark and deleting it.
- Keeping a promotional version label because it looks like a title.
- Converting a physical figure photo into anime art during background cleanup.
- Removing or changing a clear bubble, translucent effect, book, weapon, or base because it was mistaken for clutter.
- Leaving faint UI fragments, seller text, or inpainting seams.
